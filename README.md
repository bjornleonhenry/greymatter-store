# Greymatter Store

A simple key-value store web application built with Django and modern web technologies.

## Features

- Key-value data storage and retrieval
- Web-based interface for data management
- Payment integration with Stripe
- Responsive design with TailwindCSS
- Real-time updates with HTMX

## Tech Stack

- **Python** - Backend programming language
- **Django** - Web framework
- **HTMX** - For seamless user interactions
- **Stripe** - Payment processing
- **SQLite** - Database (can be changed to PostgreSQL for production)
- **TailwindCSS** - Utility-first CSS framework

## Getting Started

1. Clone the repository
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment: `source venv/bin/activate` (Linux/Mac) or `venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run migrations: `python manage.py migrate`
6. Start the development server: `python manage.py runserver`
